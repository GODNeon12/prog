# Project Repository

This repository contains the source code for a sample project with a Java backend (Spring Boot) and a simple frontend (HTML/CSS/JS).

## Structure
- `backend/` – Java Spring Boot application.
- `frontend/` – Static web assets (index.html, script.js, style.css).
- `.gitignore` – Ignored files and directories.

## Setup
1. Install Java and Maven.
2. Run `mvn spring-boot:run` in the `backend` directory.
3. Open `frontend/index.html` in a browser.

Feel free to explore and modify the code.
